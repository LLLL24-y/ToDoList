# 📝 React Todo List

A simple Todo List application built using React. This app allows users to add tasks and remove them from the list with a clean and minimal interface.

---

## 🚀 Features

* ➕ Add new tasks
* ❌ Remove tasks
* ⚡ Instant UI updates using React state
* 🎨 Simple and clean design

---

## 🛠️ Technologies Used

* React (useState Hook)
* JavaScript (ES6)
* CSS

---

## 📂 Project Structure

```
src/
│── Todo.js
│── Todo.css
│── App.js
│── index.js
```

---

## ▶️ How It Works

* The input field stores the task in a state variable (`mess`)
* When you click **Add**, the task is added to the `list` array
* Each task is displayed using `.map()`
* Clicking **Remove** deletes the task using `.filter()`

---

## 📦 Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/todo-app.git
```

2. Navigate to the project folder:

```
cd todo-app
```

3. Install dependencies:

```
npm install
```

4. Run the app:

```
npm start
```
